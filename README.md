# Adaptive Multi-Source Skill Gap Forecasting and Employability Digital Twin Framework

A framework combining LSTM-based skill demand forecasting, employability prediction,
and SHAP-based explainability into one personalised roadmap system.

## Setup
1. `python3 -m venv venv && source venv/bin/activate`
2. `pip install -r requirements.txt`
3. `docker compose up -d`
4. Copy `.env.example` to `.env` and fill in credentials
